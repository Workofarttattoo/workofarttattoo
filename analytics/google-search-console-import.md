# Google Search Console Import

Export two CSVs from GSC:

1. Query report
2. Page report

Required columns:

- query
- page
- clicks
- impressions
- ctr
- position
- date

## Analysis Goals

- high impressions / low CTR
- average positions 4-15
- keyword cannibalization
- declining pages
- emerging queries
- pages with zero impressions
- branded vs non-branded
- tattoo vs piercing
- commercial vs informational

Do not guess Search Console data. Store exports outside public web paths unless intentionally publishing a sanitized analysis.
